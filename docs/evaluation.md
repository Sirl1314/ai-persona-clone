# 评测方法论

这份文档记录三件事：怎么测、测错了怎么发现、最后用的指标体系是什么。

结论先放前面：**一个"像本人说话"的模型，不能用知识问答那一套去测。**

---

## 一、第一版评测：用贪心解码，误判"训练失败"

最初的测法是 `do_sample=False`，`repetition_penalty=1.05`，312 条测试集。

结果：**17 条重复退化**。

| 样本 | 表现 |
|---|---|
| #184 | "算了"重复 47 次 |
| #203 | "靠"重复 30 次 |
| #119 | "好呀"重复 31 次 |
| #286 | "哎"重复 42 次 |
| #064 | "妹的"重复 14 次 |

第一反应是权重量化坏了或训练崩了。但换个口径测同一批数据：

```
temperature 0.7 / top_p 0.9 / repetition_penalty 1.15
no_repeat_ngram_size 3 / max_new_tokens 64
```

| 指标 | 贪心 | 采样 |
|---|---|---|
| 重复退化 | 17 | **0** |
| > 80 字 | 19 | 5 |
| 长度中位数 | 16 | **13** |

**结论：重复 collapse 是贪心解码在长句里进 n-gram 循环，权重没坏。**
用贪心当评测口径，等于把解码缺陷记到训练头上。

这类错误很常见，因为大家默认 `do_sample=False` 是"稳定的、可复现的"。对于知识问答确实如此，对于风格化对话恰恰相反——**同一句话可以有很多种说法，强行取最高概率反而容易掉进循环**。

---

## 二、第二版评测："相同输出"不是过拟合

贪心版里还发现 31 组、72 条输出完全相同，一度判为背题。

查下去：测试集里「好！」「好呀」「我去」这类 prompt **本身就重复出现**。相同输入给相同输出是解码的必然，跟记忆无关。采样版降到 6 组 16 条。

真正该测的是**照搬率**：拿生成结果去比对训练集全部 25,583 条回复，统计 8-gram 命中。

| 指标 | 结果 |
|---|---|
| 8-gram 完全命中 | 12 / 312 = **3.8%** |
| 命中内容 | 全是「？」「是的」「当然」「好好好」这类 ≤7 字习惯用语 |
| 整段照搬 | **0 条** |

**结论：模型学到的是说话方式，不是背答案。** 短的万能口头禅本来就高频，模型学会用它们是合理的，不算背题。

判据可以选择：
- 差：「两条输出一样」→ 受 prompt 重复干扰
- 好：「8-gram 全部出现在训练集」→ 直接测记忆

## 三、第三版评测：拆成两个口径

"好不好"必须拆开，否则永远吵不清。

### 口径 A：不出错（no-error）

不答非所问、不串味、不重复退化、不角色错位。

90 条人工抽样，真错 8 条 → **91%**。

这个口径对应原始目标："能回答 90% 的问题不出错"。

### 口径 B：精准像人（strict）

在 A 的基础上还要求回答切题、风格到位、长度像本人。

同样 90 条 → **78%**。

### 为什么必须拆

同一个模型，两个数字差 13 个点。对外报哪个取决于是"能不能用"还是"有多好"。
混着报，就会出现"明明 91% 却说只有 78%"这种自相矛盾的结论。

## 四、维度级评测

720 条盲测集，9 个维度各 80 条。每维度按间隔抽 10 条人工判。

| 维度 | 通过 | 说明 |
|---|---|---|
| 日常 | 10/10 | 最稳 |
| 情感-负面 | 10/10 | 不灌鸡汤，直接接情绪 |
| 情感-正面 | 9/10 | |
| 询问 | 9/10 | |
| 图片 | 8/10 | 图片描述转文字后回答 |
| 活泼 | 8/10 | |
| 冷淡 | 7/10 | 容易答太长 |
| 互怼 | 5/10 | 偏忍让 |
| 玩梗 | **4/10** | 最弱 |

**这张表比总分有用。** 它直接指出下一步该补什么数据：互怼和玩梗的样本量最少（1,753 / 1,402），而且玩梗高度依赖具体语境。

## 五、候选重排（best-of-N）

单次采样波动大，同一输入跑四次质量差别很明显。

做法：采样 4 条，用规则打分选最高。

```python
# 长度：5-40 字 +2；<5 或 >60 字 -1
# 开头是 666/我的发/我去/稳了/哈哈/？/。。 -2
# 含 url 或单引号 -6
# 分条 1-4 行 +1，>6 行 -1
# 与 prompt 有中文 2-gram 重叠 +3
# prompt ≥10 字且零重叠 -4
# 长度 ≤3 且 prompt ≥12 字 -2
# 含 砍死/我恨/去死/杀/打死 -3
```

规则是从训练分布反推的：
- 长度区间 5-40：训练集回复中位数 11，p90 31
- 开头黑名单：采样时这几句高频出现，且通常是"没接住话"的信号
- 2-gram 重叠：判断是否真的回应了对方说的内容

效果：720 条上比单次采样提升约 3 个点。

实现见 `src/best_of_n.py`。

## 六、这套体系还能怎么用

1. **换基座时可以直接复用**：所有指标和阈值都是行为级的，不绑定 7B。
2. **做 A/B 时用同一套打分**：避免"这条看着更好"的直觉判断。
3. **回归测试**：每次重训跑同样的 720 条，看哪一维度掉点。

## 附：一条没走通的路

试过**过采样重训**（互怼/玩梗/活泼三个维度 ×2，训练集 9,815 → 13,472，1.5 epoch）。

train_loss 反而更低（2.318 vs 2.614），但效果全面变差：

- 碎片开头 14.3% → 18.5%
- 新增「稳了」霸榜 30 条
- 图片维度 9/10 → 5/10
- 出现 `'url'` 异常 token
- 抽样 90 条 55/90 = 61%

**过采样让模型学到了"不管问啥先甩一句口头禅"的开头模板**，这是典型的过拟合。loss 更低不等于更好，这在风格化任务上尤其明显。
